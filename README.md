**HOSPITAL APPOINTMENT MANAGEMENT SYSTEM**



**Project Description:**

**The Hospital Appointment Management System is designed to manage**

**patients, doctors, appointments, and appointment history.**



**Modules:**

**1. Patient Registration**

**2. Doctor Management**

**3. Appointment Scheduling**

**4. Appointment History**

**5. User Interface**



**Git Collaboration:**

**The project is developed using Git collaboration practices.**

**their work into the main branch.**
